One original joke about Monday mornings, written for the make.fun bounty

## The joke

> Monday morning I opened my inbox: 47 unread emails — 46 were from me on Friday saying 'I'll deal with this Monday.'

## How to run

```bash
python3 main.py
```

This writes the joke to `/output/entry.txt` (UTF-8, deterministic — the same
text on every run). No third-party packages are needed; Python's standard
library is all it uses.

## Why this angle

No alarm clocks, no bed filing paperwork, no software-update Mondays.
The punchline is the twist: the dreaded Monday inbox isn't full of other
people's demands — it's full of Friday-you, deferring everything to
Monday-you.
